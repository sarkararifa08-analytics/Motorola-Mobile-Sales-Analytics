# Motorola Mobile Sales Analytics Dashboard

## Project Overview

An interactive Power BI dashboard developed to analyze mobile phone sales performance, customer ratings, brand performance, and payment trends.

The project transforms sales data into meaningful business insights through interactive visualizations, KPI indicators, and dynamic filters.

## Dashboard Preview

![Motorola Mobile Sales Dashboard](Dashboard)

## Key Performance Indicators (KPIs)

The dashboard highlights the following business metrics:

- **Total Sales:** ₹769M
- **Total Quantity Sold:** 19K
- **Total Transactions:** 4K
- **Average:** 40K (metric definition to be confirmed from the Power BI measure)

## Dashboard Features

### 1. Sales Performance Analysis
- Total sales by city.
- Monthly sales and quantity trends.
- Sales performance across different mobile models.
- Sales distribution by day of the week.

### 2. Brand Performance
- Comparison of brands including Xiaomi, Vivo, OnePlus, Samsung, and Apple.
- Brand-wise total sales.
- Brand-wise quantity sold.
- Transaction comparison across brands.

### 3. Customer Analysis
- Customer rating distribution.
- Customer-related sales analysis.

### 4. Payment Analysis
- Transaction distribution by payment method.
- Comparison of UPI, Debit Card, Cash, and Credit Card transactions.

### 5. Interactive Dashboard Filters
- Mobile Model
- Payment Method
- Brand
- Day Name
- Month selection

## Business Questions Addressed

1. Which mobile brands generate the highest sales?
2. Which mobile models contribute most to total revenue?
3. How does mobile sales quantity change month by month?
4. Which cities contribute to mobile sales?
5. Which payment methods are most frequently used?
6. How are customer ratings distributed?
7. Which days of the week show higher sales?

## Key Business Value

This dashboard provides a consolidated view of mobile sales performance and helps users explore revenue trends, product performance, customer ratings, and payment preferences.

It demonstrates how Power BI can turn raw sales data into an interactive business intelligence report.
